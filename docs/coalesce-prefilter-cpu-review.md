# 合并预筛选的复制与 CPU 复核

版本保持 **2.0.0**，继续使用一个 `wintun.dll`、一套 v2 SYS 和原有 Wintun 接口。

## 已确认的问题和修改

`PbV2TryCoalesce` 原先取得空闲合并缓冲区后，先将第一个候选包完整复制到私有 Scratch，再判断该包的协议及地址族是否开启合并。开启任意一种合并功能即可触发这次复制，即使当前包只能走普通接收路径。

修复前的实际 helper 已用 IPv4、IPv6 两个独立进程分别重放 TCP/UDP 的 32 包案例：每包 1500 字节、对应模式未开启时，有 31 次整包快照，共 46,500 字节。末包因没有下一个候选而跳过。测试先完整释放缓冲区和区域、检查句柄，再以预期失败状态退出；这证明了无效复制，并不等于测出了内核 CPU 或网络吞吐量。

现在只先复制 `min(length, 40)` 字节到私有 Scratch，用它判断是否选择该合并模式。选中后仅复制剩余后缀，不重新读取前缀；完整私有快照仍交给原有 `PbCoalesceBegin` 校验长度、资格和校验和。合并后的第二次模式检查、追加包校验、容量边界、短末段关闭和缓冲区租约均继续生效。

上述未启用模式的 32 包案例只复制 1,240 字节，减少约 97.3%。可合并的正常包仍各自完整快照；流边界及容量边界原有的试探快照也继续保留。零启用掩码或两个合并缓冲区都被借出时仍为零快照。该改动没有减少必要的共享内存校验。

## 回归和成本检查

新增的 32 包测试分别编译 IPv4/IPv6，并覆盖 TCP/UDP、正常合并、其他模式、零掩码、双缓冲区忙、最小合法包、坏校验和、每四包变换流及短描述符边界。观察器逐字节确认源槽位与 Scratch 偏移一致，选中的前缀没有再次复制，且输出、原始报文、缓冲区所有权和清理结果符合预期。短描述符是 helper 的防御性边界测试，不表示 NDIS 会接纳这些报文。

另有 32 包故障注入：首次前缀复制后立即改变共享源中的协议字节。预筛选和完整校验必须继续使用已经复制的私有前缀，不能再次读取被改变的共享头。独立 oracle 检查原始有效 wire 的合并结果，共享源另按注入后的字节检查。这是对不可信映射的防御性测试，不授权应用并发修改已转让的 loan。

现有整包计数观察器同步接受 Scratch 内的后缀地址，完整统计前缀和后缀，原有合法合并总字节数、停止回收和借出归还断言保留。当前流水线分别执行普通内存和守护内存版本；独立审计还覆盖 ISO/MS volatile 模式。

新增的宿主 CPU 基准使用真实 helper 和合并核心，对比保存的旧头与当前头。IPv4/IPv6、TCP/UDP 分开，包含 64、1500、65535 字节，以及可合并、其他模式、零掩码、坏校验和和四包流边界。校验与构造在计时区域之外，记录线程周期、线程 CPU 时间和 QPC；固定处理器亲和性，预热并交替运行前后版本，保留原始样本。选中模式增加一次后缀复制调用，因此小包和失败回退也是必须检查的对照，不能只报告节省字节的案例。

宿主基准衡量当前机器上的 C 路径成本。真实 NDIS 调度、驱动池、IRQL、网卡卸载协商和目标旧系统行为仍须在相应系统上实测。

## 兼容性与生命周期

生产修改只涉及合并预筛选，不增加导入、线程、事件、分配、公开 ABI 或时钟读取。旧系统按原有运行时能力关闭不可用的卸载，新系统保留已有 RSC/URO 等能力。发送、completion 发布、槽位归还、唤醒武装和停止屏障的实现不变，并继续执行现有 32 包并发、复用和停机回归。

本轮没有确认新的发送时间混用、普通同队列逐包提交或载荷重复复制问题。跨队列发送沿用原有锁、顺序和栈预算约束；不得仅凭单包发布次数将其改成无界聚合。最终关闭仍要求公开调用者退出并归还借用，不能通过违反这一生命周期约定制造释放后访问测试。

源码基线为 `1695a4be1d9b2ea619261b1d8ee6ee7f2372bb0b845884cb8d65f100c243bc18`，本轮重新保存并核对全部 743 份源码、已有重建产物以及重新执行的静态分析。被清理的历史日志没有补造；本轮构建、测试、源文件摘要和 CPU 原始样本独立生成。

独立测试入口为 [`verify-coalesce-prefilter32.ps1`](../tools/audit/verify-coalesce-prefilter32.ps1)，CPU 入口为 [`bench-coalesce-prefilter32.ps1`](../tools/audit/bench-coalesce-prefilter32.ps1)。两者默认使用当前源码，不依赖已清理的历史目录；显式历史对比要求完整认证的旧基线。完整离线验收使用 [`validate-unified.ps1`](../tools/build/validate-unified.ps1)。固定旧快照的历史审计不放宽为任意源码；旧观察器的原始摘要和本轮仅计数适配的差异单独保存。
