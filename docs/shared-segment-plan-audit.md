# 共享分段 plan 校验审查

日期：2026-10-29。当前 SYS 的 `PbV2Describe` 只从有界的报文字节调用 `PbPlanSegments`，随后读取栈上的 plan；没有调用 `PbWriteSegment` 或 `PbWriteSegmentBatch`，也没有接收用户提供的 `PB_SEGMENT_PLAN`。本次确认的是 SYS 同时链接、DLL 实际调用的共享写出函数缺口，尚未发现该缺口在当前 SYS 中的可达路径。

## 已复现的问题

原 `ValidPlan` 仅检查结构字段之间的长度和计数关系。实际源缓冲区为 64 字节，把 SourceLength 改为 76、PayloadLength 改为 36、SegmentCount 改为 3，保留 HeaderLength=40、Mss=12，再请求 index=2，可使写出函数从源缓冲区末尾继续读取 12 字节。保护页测试捕获访问异常 `0xc0000005`。原接口没有独立源长度，无法仅凭 plan 证明源缓冲区边界。

范围内的偏移也可能不正确。例如把 PseudoDestinationOffset 改为 0，原函数仍返回成功，并以 IP 头部前四字节计算伪首部校验和。伪造的 IP 版本、L4 偏移和协议，或者生成 plan 后改变 TCP 头长、SYN、分片字段，也没有与源报文重新核对。它们可能产生错误报文；不能仅凭这些语义问题宣称存在越界写入。

## 长期修正方案及实施

采用四步闭环：先退役无法证明源边界的入口，再统一请求验证，随后约束组件协商和迁移，最后将攻击用例纳入持续验证。当前代码已实施前三步及第四步的离线验证；真实驱动验收单独进行。

| 阶段 | 修正与验收要求 |
| --- | --- |
| 旧入口退役 | V2 表保留 280 字节、函数位置和签名，两个旧 writer 只清零有效计数指针并返回 UNSUPPORTED；不可访问的 source、plan、输出表均不得被读取 |
| 统一验证 | 单段和批量共用 PrepareWrite，先快照和验证整批请求，再用同一解析器验证 plan，最后从局部规范 plan 写出；不增加句柄、分配或缓存 |
| 协商与迁移 | 分段扩展 1.1 必须同时提供独立源长度、旧入口退役和输出不重叠三项能力；启用实验卸载必须显式确认使用新入口 |
| 持续验证 | 正向 wire oracle、保护页、元数据/输出别名、地址回绕、旧二进制入口、能力缺失拒绝及部分完成均进入正式测试；同一源码指纹构建组件 |

Checked 入口要求调用者从所拥有的缓冲区提供独立 sourceLength。PrepareWrite 在写入前检查源、plan、输出表、计数指针和各输出声明容量的地址回绕与相互重叠，并快照输出表，避免前面的输出覆盖后面的指针或容量。单次最多 32 个输出；零容量返回 NO_SPACE，后续容量不足保留已完成前缀。非法参数、地址范围或别名保持所有输出不变；请求几何合法后，计数归零，报文或 plan 无效返回 INVALID。

plan 的语义以报文解析器为唯一依据，不维护第二套协议规则。逐字段比较源长度、负载、MSS、段数、IP/传输协议、头部及伪首部偏移和 UDP 校验和标志，并使用解析器生成的局部 plan。填充字节不参与比较。整批只解析一次，没有逐段重新解析或额外负载复制。非空输出范围在固定数组中按地址排序后检查相邻范围，已按地址排列的输出只需线性检查，最坏排序受 32 项约束。空范围不参与排序，不能遮蔽包含关系中的重叠。

产品 PE/驱动包升级为 2.0.0，V2 表报告 2.1；Rust crate 升级为 3.0.0。分段扩展保留 32 字节布局、报告 1.1，Rust 加载时拒绝缺少任一必需能力、方法或完整前缀的 DLL。未知新增能力和同一主版本的后续 minor 可以接受。旧 V2 writer 不提供回退实现，也不能通过配置重新启用。

C 调用者协商分段扩展后，启用实验卸载须同时设置 PB_OPEN_EXPERIMENTAL_OFFLOADS 和 PB_OPEN_CHECKED_SEGMENTS；旧的单标志请求在会话分配前返回 UNSUPPORTED。Rust 在确认扩展后自动设置确认标志。需同步更新仓库绑定、DLL、SYS、probe 和构建清单；实际 VPN 应用未在本次修改。Checked 入口仍要求如实提供可读长度、有效指针，并在调用期间保持输入不变；它不探测任意指针的实际分配大小，不替代跨线程同步。

## 回归与验证边界

正式测试覆盖单段与批量入口的 20 类畸形或过期 plan、64 个截断长度、真实保护页、失败后输出与批量 Length 不变，以及有效报文的正向对照。十万报文变异测试对每个有效 plan 再做变异，分别执行单段和批量写出。packet_request_tests 对旧入口传入不可访问页，检查退役路径不读参数；同时验证源/plan/输出表/计数/目标别名、指针回绕、相邻容量、零容量与部分完成。

Python oracle 继续检查 IPv4/TCP 选项、IPv6 扩展与路由、UDP 零校验和、序号、末段标志及批量部分完成。C/Rust 检查扩展前缀、V2 布局、旧配置早期拒绝、能力缺失和后续 minor 兼容。Rust 测试故意替换旧分段槽位，证明安全包装使用新入口。

统一离线入口为 `tools/audit/validate-dll-lifecycle.ps1 -SkipBenchmark`，包含 Tests、Safety、Driver、Probe、Api、旧版 DLL 编译和 SYS/DLL 静态分析；结果按源码指纹保存在 out/dll-lifecycle-validation 和 out/packet-path-v2。宿主基准入口 `tools/audit/bench-segment.ps1` 测量批量验证、分段、复制与校验和；可传入含 packet.c/packet.h 的 BaselineDirectory 做五轮交替顺序对比。覆盖 MSS=16/1024、批量 1/8/32，固定可用 CPU，保留 QPC、线程周期和源哈希，结果位于 out/segment-bench。这些数值不能替代真实驱动吞吐验收。最初的越界复现保存在 out/packet-plan-audit，本次局部日志与源快照在 out/segment-plan-remediation。验证不安装或运行驱动。
